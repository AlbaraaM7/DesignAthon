# ORBIT — Student Micro-Bounties & Creative Sprints

> **ORBIT** connects UAE university students with 48-hour commercial sprints, escrow-backed AED rewards, and verified portfolio proof-of-work—turning campus talent into career credibility.

Developed for **The DesignAthon 2026**, hosted by the Graphic Design Club at Rochester Institute of Technology (RIT) Dubai in partnership with **+twe**.

---

## 🚀 Overview

The traditional university internship model is broken. Students face the classic catch-22 of needing experience to get hired while balancing demanding coursework and exams, leading to hundreds of unanswered applications. Meanwhile, regional startups, university research laboratories, and campus organizations struggle to find agile, skilled talent for discrete, high-impact tasks.

**ORBIT** bridges this gap through the **48-Hour Bounty Protocol**:
- **Milestone-Scoped Sprints:** 48-hour to 4-day tasks designed around academic calendars.
- **Guaranteed Escrow Payouts:** AED 200 – AED 1,200 locked in escrow and released upon sponsor sign-off.
- **Verified Proof-of-Work:** Cryptographic portfolio badges replacing unverified resume claims.
- **Zero Recruiter Bureaucracy:** Fast, merit-based applications directly on campus tasks.

---

## ✨ Features

- **Cosmic Scrollytelling Experience:** Built with WebGL volumetric light rays and GSAP ScrollTrigger stargate portal expansion.
- **Live Filterable Bounty Explorer:** Instant search and category filtering across UI/UX Design, Frontend Web, 3D & Motion, AI & Python, and Branding.
- **Proof-of-Work Submission Flow:** Interactive modal with deliverable checklists and live preview.
- **Interactive Semester Earnings Calculator:** Dynamic dual-slider calculator with real-time count-up animations.
- **Judges Deliverable Modal:** Dedicated Problem & Solution tab with survey data from 142 UAE university students.

## 🛠️ Tech Stack

- **Framework:** React 18, Vite 6
- **Styling:** Tailwind CSS, PostCSS, Glassmorphism
- **Animations & Scrollytelling:** GSAP, ScrollTrigger, OGL (WebGL)
- **Icons:** Lucide React
- **Typography:** Syne (display), Plus Jakarta Sans (body), JetBrains Mono (data metrics)

## 📦 Getting Started

### Prerequisites
- Node.js (v18+)
- npm or yarn

### Installation

```bash
# Clone repository
git clone https://github.com/<username>/<repo-name>.git
cd <repo-name>

# Install dependencies
npm install

# Start development server
npm run dev
```

### Production Build

```bash
npm run build
npm run preview
```
